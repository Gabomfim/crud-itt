🚀 API de Gerenciamento de Usuários

Sistema CRUD ITT - FastAPI

Bem-vindo à API de Gerenciamento de Usuários! Esta API permite gerenciar usuários com operações CRUD completas, autenticação JWT e validação de dados.

🔗 Endpoints Disponíveis:

👤 Gerenciamento de Usuários

GET /usuario/{username} - Obter informações do usuário por nome
GET /usuario?minimum_age={idade} - Obter usuários com idade mínima
POST /usuario - Criar um novo usuário
PUT /usuario/{username} - Atualizar informações do usuário
DELETE /usuario/{username} - Deletar um usuário

🔐 Autenticação

POST /auth/login - Fazer login e obter token JWT
POST /auth/logout - Fazer logout e invalidar token
