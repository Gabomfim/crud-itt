🚀 User Management API

BANANANANANANANNANANA

Welcome to the User Management API! This API allows you to manage users with full CRUD operations.

Available Endpoints:

GET /usuario/{username} - Get user information by username
GET /usuario?minimum_age={age} - Get users with minimum age
POST /usuario - Create a new user
PUT /usuario/{username} - Update user information
DELETE /usuario/{username} - Delete a user
